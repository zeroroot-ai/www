## What is ZeroRoot AI?

ZeroRoot AI is a platform for teams that need to deploy AI agents at scale — with the security posture, compliance controls, and operational tooling that modern enterprises demand.

Every agent runs inside a cryptographically isolated execution environment. Every action is authorized through an open FGA policy engine. Every secret is managed by a zero-trust vault. You get full observability, not just logs.

## Core capabilities

<div class="card">

### Agents, tools, and plugins — unified

Author your AI components once using the open Apache-licensed SDK. Deploy them as agents (orchestrators), tools (executors), or plugins (bridges) without rewriting your logic.

</div>

<div class="card">

### Zero-trust by default

SPIFFE/SPIRE mTLS between every component. Envoy ext_authz on every RPC. OpenFGA fine-grained authorization on every resource. No ambient authority — ever.

</div>

<div class="card">

### Secure execution substrate

Untrusted code runs inside Firecracker or Kata microVMs via the open-source setec operator. Tenant isolation is guaranteed at the hardware-virtualization layer, not the OS process layer.

</div>
